★ Current work — source field

Speaker attribution in transcript segments

Stage 5 (diarise) tags each segment with a source field derived from resemblyzer voice embeddings compared against Tommy's reference embedding. This value flows through the upload stage (majority-voted per 60s window) into the database, and ultimately tells the RAG system who is speaking — so Tommy can say "I" for his own words, and attribute others appropriately.

"TV" Tommy Vance is speaking — cosine similarity ≥ 0.79 against reference embedding. In chat responses: first person ("I played...", "I opened with..."). Covers the bulk of every broadcast.
"uncertain" Voice does not match Tommy — likely a guest, interviewee, or another DJ doing a soundbite. In chat responses: attributed as "someone said" or "source unknown". Content is still valid archive evidence and should be surfaced when relevant to the user's question.
null Diarisation has not yet been run on this episode (1981+ pending). Treat as potentially Tommy but do not definitively attribute. Use "on the show" or "from the broadcast" phrasing. Not an error — the archive is being processed in phases.
